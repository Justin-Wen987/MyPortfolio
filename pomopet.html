PomoPet

A small reward for getting things done.

March–April 2026

Gamified Pomodoro & to-do tool · Individual project · HTML / CSS / JavaScript

Overview

My role
Wrote the design document first, then defined the reward loop, pet rarities and interface requirements.
The loop
Finish a task or focus cycle, earn a token and draw a pet. Recycle pets for coins; exchange 100 coins for another token.
A design detail
Refined the draw animation by specifying its horizontal movement and gradual slowdown in stages.

I set the gameplay, interface and visual requirements. AI assisted parts of the JavaScript and generated the pet artwork from my prompts.

During self-testing, I kept completing tasks and focus sessions because I wanted the rare dragon. Once the collection is complete, though, there is little else to play. Continued use would depend on how useful the timer and task list are.
